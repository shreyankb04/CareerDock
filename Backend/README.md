\# CareerDock



CareerDock is an AI-powered career preparation platform that helps students analyze resumes, detect skill gaps, optimize ATS scores and prepare for interviews using Generative AI.



\## Features



\- Resume Upload

\- Resume Analysis

\- ATS Score

\- Skill Gap Detection

\- AI Interview Questions

\- Resume Builder



\## Tech Stack



\- React

\- Node.js

\- Express.js

\- MongoDB

\- JWT

\- Gemini AI
